# IpehPijet

Website statis untuk layanan pijat IpehPijet. `index.html` adalah halaman utama untuk hosting; `ipehpijat.html` dan `ipehchrome.html` disimpan sebagai salinan sumber.

## Preview lokal

Jalankan server statis dari folder ini, lalu buka alamat lokalnya:

```powershell
python -m http.server 8000
```

Buka `http://localhost:8000`.

## Deploy

Folder ini dapat di-deploy langsung ke Vercel sebagai situs statis tanpa langkah build.

## Isi

- `assets/images/` — gambar dan logo situs
- `assets/source/` — file sumber aset
- `PHOTO-CREDITS.md` — kredit dan lisensi foto
- `ipehheadshot.jpeg`, `namecard.jpeg`, dan gambar di folder utama — aset tambahan proyek
